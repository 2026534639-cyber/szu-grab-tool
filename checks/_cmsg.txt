小窗口适配 + 一条命令同时更新两个版本

小窗口（用户报「适配下小窗口」）：
- 窗口尺寸改按 Windows 可用工作区（刨掉任务栏）收口；原来 height 有写死的
  下限 max(height, s(560))，1366x768 + 150% 缩放时会算出 840 —— 比屏幕还高，
  底部按钮被顶出屏幕。
- 左栏改成可滚动：内容自然高度约 830px，1366x768 可用高度只有 ~728，
  光调尺寸治不了。滚动条只在装不下时出现；滚轮逐个绑到左栏子控件
  （跳过 Text/表格/滚动条，它们自己要用滚轮）。
- 小屏上日志框默认变矮（8 行 → 5 行），把空间让给按钮。
- 关窗时取消挂着的 after 任务，不再刷 invalid command name。
- 滚动条显隐改用自己的状态标记（winfo_ismapped 在窗口未映射时恒为假）。
- checks/test_smallwin.py：5 种屏幕 x 2 种缩放，检查不超屏 + 滚到底能点到
  「开始抢课」按钮；另测 1024x768 老机器。

一条命令两份一起更新（用户要求「两个版本都要一起更新」）：
- build.bat all：自己用 + 给大家用一次做完，并复制到桌面（三件套）。
- 覆盖桌面文件前用 checks/ensure_not_running.py 检查有没有在运行
  （原来用 tasklist + find，find 会被 PATH 影响解析成 MSYS 的 GNU find）。
